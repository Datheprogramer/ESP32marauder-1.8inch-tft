# ESP32Marauder — My Custom Builds

A collection of my custom builds for [ESP32 Marauder](https://github.com/justcallmekoko/ESP32Marauder) (j4f).

> Some builds may be outdated, unfinished, or broken.

---

## Important Notes

- No libraries are included in this repo.
- No prebuilt firmware images are provided.
- For 1.8" TFT display schematics, use my `User_Setup` configuration.

---

## Required Libraries

Download the required libraries from the official ESP32 Marauder repository:

[ESP32 Marauder Libraries](https://github.com/justcallmekoko/ESP32Marauder/tree/master/esp32_marauder/libraries)

---

## Required Arduino IDE Version

You must use **Arduino IDE 1.8.19** for these builds.

Download it here:

[Arduino IDE Downloads](https://www.arduino.cc/en/software/)

Scroll down and select **"Legacy IDE (1.8.19)"**.

---

## Firmware Build tt

I do not provide build tutorials.

Follow the official installation/build guide here:

[ESP32 Marauder Firmware Installation Guide](https://github.com/justcallmekoko/ESP32Marauder/wiki/installing-firmware-from-source)
